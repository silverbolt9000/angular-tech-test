Explicação técnica

trackBy

O trackBy evita que o Angular recrie todos os elementos da lista a cada atualização.

Utilizando o id como identificador único, apenas o item alterado é renderizado novamente.

OnPush

A estratégia OnPush reduz ciclos desnecessários de detecção de mudanças.

O componente só é reavaliado quando há alteração de referência, eventos internos ou observables/signals atualizados.

Estratégia Default

Utilizando Default, o Angular executaria change detection em toda a árvore de componentes a cada evento assíncrono.

Em listas grandes isso aumenta significativamente o custo de renderização.
